# NewPipe Downloader

A lightweight, open-source Android application focused on video and audio downloads.

NewPipe Downloader is a simplified fork of [NewPipe](https://github.com/TeamNewPipe/NewPipe), adapted to focus on downloading rather than the full streaming experience.

## Features

- Download video and audio in supported formats and available qualities.
- Choose from available download options.
- Save downloaded files locally on your device.
- Minimal interface focused on downloading.
- Open-source Android project.

## Project Status

This project is a work in progress. Features, compatibility, and the user interface may change as development continues.
